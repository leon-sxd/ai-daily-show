# assets 目录说明（私有素材自备）

本目录**不附带任何成品音频或封面**。以下素材由使用者自备授权后放入对应位置：

## BGM

- 默认路径：`assets/bgm.wav`
- 规格参考：44.1kHz 立体声；每期取前 90s；合轨 AAC 256k、开头 30ms 淡入。
- 自备要求：确认拥有该音乐在目标平台的公开传播与再分发权；无授权时请替换为自有 / 可商用纯音乐。

## 封面成品图

- 成品封面不入库；版式占位见仓库 `templates/covers/`。
- 横封槽位 4:3（1773×1330），竖封槽位 3:4（1330×1773）；竖封避让顶部 8%、底部 20%、右侧 13%，底部安全区不放文字标签。
- 封面内球体 / 圆形徽标必须为标准正圆（宽高比 1:1）。

## 为什么仓库里看不到这些文件

`.gitignore` 已排除 `*.wav`、`*.mp3`、`*.mp4` 与 `assets/covers/` 下的成品图，避免私有素材被误提交到公开仓库。
