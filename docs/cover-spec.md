# 封面规范

## 槽位

| 用途 | 比例 | 像素 |
|---|---|---|
| 横封 | 4:3 | 1773×1330 |
| 竖封 | 3:4 | 1330×1773 |

不要出 16:9 / 9:16 封面，避免被平台槽位裁切。

## 一致性

- 同一刊期横封、竖封为同一套主视觉概念、同一套文案与配色；不得横版一套图形、竖版另一套。
- 竖封不独增条目列表、地球、大脑、手写划线、枝叶等横版没有的元素。

## 几何与避让

- 球体、星球、圆形徽标必须标准正圆（宽高比 1:1），出图后放大中心球体复核。
- 竖封避让顶部 8%、底部 20%、右侧 13%；底部安全区纯净，不放文字标签。
- 深色低饱和 + 琥珀拓扑，与成片风格统一。

## 角标口径

- 日报「今日观察」，周报「本周观察」；与视频主线镜、结尾镜、浏览器标题一致。
