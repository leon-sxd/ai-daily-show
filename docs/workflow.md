# 生产流程

1. **选题**：检索当期 AI 领域热点；热点不足时加深概念讲解并补具体举例，不空泛罗列。逐条记录获悉渠道、时间点、外部链接（有则贴）与口径说明，整理信息来源清单——仅后台存档，不写进视频画面。
2. **工程**：横版 `templates/landscape`、竖版 `templates/portrait`；更新当期场景文案；先跑 `lint` 0 错误再渲染。
3. **渲染静音源**：横版 1920×1080、竖版 1080×1920，90s，30fps。
4. **合轨**：用 `tools/mux-bgm.ps1`（Windows）或 `tools/mux-bgm.js`（跨平台 Node）合入自备 BGM；AAC 256k、开头 30ms 淡入、取前 90s；保留静音源备份。
5. **物料**：标题（主推 + 备选）、简介文案、信息来源清单、发布物料文档，按期次归档到本地目录（不入库）；封面引用本地固定模板，物料文档记录模板路径，不向期次目录复制封面副本。
6. **发布**：人工在各平台创作者中心上传成片、粘贴标题与简介、上传封面、核对裁剪框后自行发布；仓库不含平台填表 / 登录态脚本。

## 归档约定（本地工作目录，不入库）

- 日报：`ai_daily/<日期>/`：横 / 竖成片、发布物料、信息来源清单。
- 周报：`ai_weekly/<日期>/`：同上。
- 封面模板在本地素材目录留存一份，期次归档目录不复制副本；物料文档写明所引用的模板路径。

## 固定口径

- 角标与浏览器标题：周报「本周观察」，日报「今日观察」；封面角标、主线镜、结尾镜、浏览器标题四处一致。
- 平台话题与 @：按目标平台规则与当期主题自行拟定，供人工粘贴；仓库不内置任何平台账号、固定话题或 @ 名单。示例占位：`#AI模型 #科普`。
