# 封面占位版式

仓库只提供空白占位与槽位约束，**不附带成品封面图**；成品封面由作者本地生成 / 设计后自行使用，不入库。

## 槽位尺寸

| 用途 | 比例 | 像素 |
|---|---|---|
| 横封 | 4:3 | 1773×1330 |
| 竖封 | 3:4 | 1330×1773 |

禁止出 16:9 / 9:16 封面，否则上传后被平台槽位裁切。

## 约束

- 同一刊期横封与竖封必须是同一套主视觉概念、同一套文案（角标 + 标题 + 副标题）与配色。
- 所有球体、星球、圆形徽标为标准正圆（宽高比 1:1），出图后放大复核，不得拉成椭圆。
- 竖封避让顶部 8%、底部 20%、右侧 13%；底部安全区纯净，不放文字标签。
- 深色低饱和 + 琥珀拓扑，与成片风格统一。
- 角标按刊期区分：日报「今日观察」，周报「本周观察」；与视频主线镜、结尾镜、浏览器标题同一口径。
