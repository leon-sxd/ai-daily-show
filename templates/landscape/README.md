# 横版 16:9 模板

- 画布 1920×1080，30fps，总时长 90s，10 镜结构。
- 宿主 `index.html` 通过 `data-composition-src` 挂载 `compositions/scene-01.html` … `scene-10.html`。
- 每个子组合：根节点 `data-composition-id` 与宿主挂载 id、`window.__timelines` key 三者一致；片段用 `class="clip"` + `data-start` / `data-duration`；注册一条 paused 的 GSAP 时间线。
- 公开仓库内的模板文案为脱敏占位；正式出片时替换为当期选题，真实热点文案与来源不入库。
- 角标口径：日报「今日观察」、周报「本周观察」；封面角标、主线镜、结尾镜、浏览器标题四处保持一致。
- 配色与竖版规范一致：背景 `#13161b`，主文字 `#f2f4f7`，次级文字 ≥`#c2cad4`，强调色 `#e0a45c`。
